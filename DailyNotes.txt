Operators:
		
		1)arithmetic operators        + -  * /  %  //(floor division)  **(exponent/power operator )
		2)relational operators         >,<,>=,<= ,==,!=
		3)logical operators				and ,or,not
											and-->if both arguments are True then only the result is True 
											or-->if  atleast one argument is True the result is True 
											not-->complement
											
											True and False-->False
											True and True-->True
											True or False-->True
											not False -->True
											
												0 means False
												non-zero means True
					x and y		-->if x is evaluates to false return x otherwise return y
					10 and 20   
											empty string is False 	
											
											1 0 -->1
											0 1 -->1
											11-->0
											00 -->0
		4)bitwise operators          &,|,^,~,<<,>>
		
							&	-->if both bits are 1 then only the result 1  otherwise result is 0
							|	-->if atleast one bit is 1 then only the result 1  otherwise result is 0
							^-->if  bits are  diff  then only the result 1  otherwise result is 0
							~-->bitwise complement operator
